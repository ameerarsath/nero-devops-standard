# NERO response templates

> Templates only. Antigravity publishes filled copies in its own `02_antigravity_to_codex/` subdirectories. Do not edit this file to respond.

Every response starts with these fields:

```text
Message ID: {unique ID}
Task ID: {task ID}
Sender: Antigravity
Recipient: Codex
Message Type: {ACKNOWLEDGEMENT | QUESTION | RESULT | BLOCKER}
Timestamp: {ISO 8601 with offset}
Related Message ID: {assignment or question ID}
Current Task Status: {allowed lifecycle status}
```

## Acknowledgement

`acknowledgements/ACK-{assignment-message-id}.md`: confirm scope, authorization ID, files, and start status.

## Question

`questions/QUESTION-{task-id}-{sequence}.md`: state exact ambiguity, affected paths, options, recommended option and reasoning, and the work stopped pending an answer.

## Blocker

`blockers/BLOCKER-{task-id}-{sequence}.md`: state observed failure, reproduction, impact, work still possible, and requested resolution.

## Result

`results/RESULT-{task-id}.md` (add a sequence for subsequent results): summarize implementation; list modified files, contract and security behavior, tests with exact commands/results, baseline checks, deviations, unresolved findings, and evidence paths. Report `IMPLEMENTATION_COMPLETED`; Codex alone decides acceptance.
