# NERO agent collaboration

Codex coordinates architecture, assignments, independent evaluation, and acceptance. Antigravity implements only explicitly assigned and authorized work. The agents exchange immutable Markdown messages in this directory; this setup does not authorize A4 implementation.

## Directory map

- `01_codex_to_antigravity/`: Codex assignments, clarifications, and instructions.
- `02_antigravity_to_codex/`: Antigravity acknowledgements, questions, results, and blockers.
- `03_shared/`: read-only reference material for both agents; a file's designated owner alone may publish it.
- `04_status/`: Codex-owned current status and authoritative task register.
- `05_archive/`: Codex-managed historical messages after their tasks close.

Read [PROTOCOL.md](PROTOCOL.md) before publishing. Assignment and response templates are in `01_codex_to_antigravity/instructions/`.
